      Getting started

      1. Install a local model (one time, needs internet)

      Jarvis uses a language model that runs on your own computer. You need to download the model server and one model once. After that, everything works without internet.

      1. Download and install Ollama from https://ollama.com/download.
      2. Open a terminal and download a model. Pick one that fits your memory:
        • 8 GB RAM: ollama pull qwen3:1.7b (about 1.4 GB) or ollama pull llama3.2:3b (about 2 GB)
        • 16 GB RAM: ollama pull qwen2.5-coder:7b (about 4.7 GB, good for code) or ollama pull gemma3:4b (about 3.3 GB)
        • 32 GB+ RAM or a big GPU: ollama pull qwen2.5-coder:14b (about 9 GB)
      3. Make sure Ollama is running (Windows/macOS: start the Ollama app; Linux: ollama serve).
      4. In Jarvis, open Settings and pick the model, or leave it on automatic.

      Prefer llama.cpp or LM Studio? Choose "OpenAI-compatible server" in Settings and enter its local address (for example http://127.0.0.1:8080/v1).

      2. What stays on your computer

      • Your chats, tasks, settings and history are stored in the Jarvis data folder (shown in Settings).
      • Jarvis talks only to the model server on this computer. It refuses non-local model addresses unless you explicitly allow them in Settings.
      • Files like .env, private keys and credential files are never read or shared with the model. Values that look like passwords or API keys are replaced with [REDACTED].
      • Jarvis does not browse the web. Smaller local models can be wrong or out of date, so check important facts against official documentation.

      3. Working on a software project

      1. Go to Project and choose your project folder. Jarvis reads only inside that folder.
      2. In Chat, keep "Use project files" on. Jarvis searches the project and shows which files it used under each answer.
      3. When Jarvis writes a full file, use Propose as file change on the code block. You'll see a diff and warnings before anything is written, and you can undo it later.
      4. Run tests and builds from Project → Commands. Commands Jarvis doesn't recognize, and anything that deletes, installs, migrates or uses the internet, need your approval first.
      5. Press Ask Jarvis about this output to debug using the real error messages.

      Modes

        Troubleshooting

        • "Ollama is not running": start the Ollama app, or run ollama serve in a terminal, then click the model status at the top.
        • "Model is not installed": run ollama pull <model> once while online, or choose another model in Settings.
        • Answers are slow: the first answer loads the model into memory. Choose a smaller model or lower the context size in Settings.
        • Answers are wrong or vague: attach the relevant files, switch to "Detailed", or use a larger model. Small models make mistakes, so always review code before applying it.
        • A command fails with "not found": that tool isn't installed or isn't on your PATH.

        Keyboard: Enter sends, Shift+Enter adds a new line, Esc closes dialogs.
